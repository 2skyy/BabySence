## 공통 규격 (모든 컷 동일)
- **세로(portrait) · 라이트 모드 · 1배수.** 11번(다크 모드)만 예외로 다크.
- 촬영: `xcrun simctl io booted screenshot <파일명>.png` → 원본은 3배(1206×2622) → 1배수 변환: `sips --resampleWidth 402 *.png` (402×874가 됨. 원본 폭이 다르면 ÷3).
- 스낵바("기록했습니다" 등)가 사라진 뒤, 키보드 내린 상태에서 찍기.
- 파일명은 아래 각 항목의 번호-이름 사용.

## 사전 준비 A — 한 번만 (촬영 전날까지)
1. **테스트 계정 + 아기 프로필**: 팀 공용 계정으로 로그인 → 온보딩에서 아기 등록. 가명(예: '봄이'), **남아**, **생년월일 = 촬영일 − 약 2개월 10일** (예: 촬영일이 10/26이면 2026-08-16) → 체온 판정의 0~3개월 구간에 들어감. 몸무게 5.6kg, 키 58cm 입력.
2. **공지 시드**: Supabase SQL Editor에서 `supabase/migrations/012_add_contents.sql` → `supabase/seed_contents.sql` 순서로 실행. 앱 전체 탭 → 공지사항에 글이 뜨는지 확인.
3. **상담·피부 서버**: iOS 시뮬레이터의 기본 API 주소는 `http://127.0.0.1:8000` (lib/core/constants/api_config.dart). `server/`에서 FastAPI를 로컬로 띄우거나, 실행 시 `flutter run -d "iPhone 17" --dart-define=API_BASE_URL=<배포 서버 주소>`. **촬영 전에 상담 1회 왕복 확인**, 단 리허설에서 과도하게 호출하지 말 것(사용자별 호출 상한·서킷 브레이커에 걸리면 촬영 때 안내문만 나옴).
4. **피부용 사진 1장**: 얼굴이 안 나오는 아기 팔·볼 피부 근접 사진(개인정보 없는 것), 4MB 이하. 시뮬레이터 창에 드래그해 사진 앱에 넣어 두기.
5. **예방접종 밑작업**: 홈 → 예방접종에서 출생 차수(BCG·B형간염 1차)를 완료로 표시하고 접종일을 생후 0~1개월의 과거 날짜로 수정(완료 항목의 날짜는 수정 가능) → 완료/예정이 섞인 자연스러운 목록.

## 사전 준비 B — 7일치 기록 (24시간 원·7일 추이·주간 뷰용)
기록 입력 화면은 시각(오전/오후 시:분)만 받아 **오늘 기록만 넣을 수 있음** → 과거 날짜 소급 입력 불가. 둘 중 하나로:
- **방법 1 (권장, D-6부터 매일 2분)**: 매일 수유 3~4건(분유 120~160ml, 가끔 모유), 배변 2~3건(소변/대변-황금변), 낮잠 1건. **밤잠은 다음 날 아침에** '시작 오후 9:30 / 종료 오전 6:50'으로 입력하면 날짜가 자동으로 전날 밤~오늘 아침으로 잡힘.
- **방법 2 (하루 만에)**: Supabase SQL Editor에서 과거 6일치 insert — `feeding_records(baby_id, feeding_type('formula'|'breast'), amount_ml, fed_at)`, `diaper_records(baby_id, diaper_type('urine'|'stool'), stool_state('golden'…), recorded_at)`, `sleep_records(baby_id, sleep_type('night'|'nap'), started_at, ended_at)`. baby_id는 babies 테이블에서 조회.

## 촬영 순서 (D-day — 순서를 바꾸지 말 것, 데이터가 서로 물려 있음)

**0) 당일 아침 워밍업**: 어젯밤 밤잠 입력(위 방법) + 오늘 수유 2건·배변 1건 입력 → 홈 타일과 오늘 원이 채워짐. 설정에서 '시간에 따라 자동' 끄고 라이트 고정.

**1) 홈** `01-home.png` — 슬라이드 1(표지)·10(라이트/다크 쌍)
보여야 할 것: 상단 아기 이름, 다음 수유 카드, '오늘의 기록' 9칸 그리드(수유·배변·수면·체온 타일에 오늘 값, '기록 없음' 아님). 맨 위 상태라 상담 FAB는 안 보이는 게 정상(깨끗한 컷).
준비: 워밍업 완료 상태 그대로.

**2) 피부 살펴보기 결과** `02-skin.png` — 슬라이드 5
보여야 할 것: '피부 살펴보기' 제목, 단계·보이는 것·지금 할 수 있는 것(병명·확률 없음), "사진으로는 병을 가려내지 않습니다" 문구, 하단 응급 안내.
준비: 홈 → 피부 → 앨범에서 준비한 사진 선택 → 확인하기. **반드시 체온 38.2℃를 입력하기 전에 찍을 것** — 최근 12시간 내 38.0℃ 이상 기록이 있으면 3개월 미만 코드 잠금이 단계를 '즉시 진료'로 상향시킴(그건 슬라이드 8의 이야깃거리이지, 슬라이드 5 컷이 아님).

**3) 체온 입력 + 상담 권장 판정** `03-temp-consult.png` — 슬라이드 4
보여야 할 것: '상담 권장' 빨간 판정 카드 + "3개월 미만 발열은 진료가 필요하니…" 안내 + 바로 아래 **의료기기 아님 고지 카드**가 한 프레임에.
준비: 홈 → 체온 → 피커로 38.2℃, 증상 '없음', 측정 시간 그대로 → 저장. 저장 후 판정 카드와 고지가 함께 들어오게 스크롤 조정(위 피커는 잘려도 됨).

**4) AI 상담 대화** `04-chat.png` — 슬라이드 5
보여야 할 것: '종합 상담' 제목, 상단 한 줄 고지, 내 질문 + AI 답변이 한 프레임에.
준비: 홈에서 살짝 스크롤해 '아이에 대해 물어보기' FAB를 띄워 진입. 질문 예: "오늘 38.2도까지 열이 났는데 밤사이 무엇을 지켜봐야 할까요?" — 방금 넣은 체온 기록이 맥락으로 전달되므로(개월 수·최근 기록) 답이 그 기록을 짚음. 답변이 끝까지 출력된 뒤 촬영. 서버 연결 필수.

**5) 예방접종 목록** `05-vaccination.png` — 예비(슬라이드 6 보조·알림 이야기)
보여야 할 것: 완료(체크+날짜)와 예정(예정일)이 섞인 일정, 접종 전 확인 목록(최근 체온 38.2℃가 "진료실에서 말할 거리"로 뜨면 그대로 두기 — 좋은 디테일).
준비: 사전 준비 A-5 완료 상태. 홈 → 예방접종.

**6) 기록 탭 24시간 원** `06-day-ring.png` — 슬라이드 6
보여야 할 것: 일(日) 보기 큰 원 — 밤잠 호(arc), 수유·배변 점, 옆 범례, 오늘 날짜 머리글.
준비: 기록 탭 → '일' 눈금, 오늘. 워밍업 기록이 그려짐. (보너스 컷: '주' 눈금으로 7개 원이 늘어선 `06b-week-rings.png` — 준비 비용 0, 슬라이드에서 고를 수 있게.)

**7) 분석 탭 최근 7일** `07-weekly.png` — 예비(슬라이드 6 보조, 7일 추이)
보여야 할 것: '최근 7일' 카드(수유 n회·하루 평균, 배변, 수면 합계, 최고 체온 38.2℃) + 아래 '판정 기록'에 방금의 **체온 · 상담 권장** 카드가 보이게.
준비: 3번 이후라면 자동으로 채워져 있음. 분석 탭에서 두 섹션이 한 프레임에 오게 스크롤.

**8) 수면 소음 측정 결과** `08-noise.png` — 예비(슬라이드 4·질의응답 대비)
보여야 할 것: '수면 소음 결과' — 판정(정상/주의/개선 권장), 평균 n.n dB, 근거 안내문. 소음은 '상담 권장' 대신 '개선 권장'으로 표기되는 것 자체가 설명거리.
준비: 홈 → 소음 → 낮잠 선택 → 측정 시작 → **조용한 방에서 60초 이상**(1초 1표본, 30표본 미만이면 판정 보류) → 중지 → 결과 화면. **6·7번 뒤에 찍을 것** — 측정이 짧은 수면 행과 소음 판정을 새로 만들어 원·판정 기록 컷을 오염시킴. 주의: 시뮬레이터는 맥 마이크를 쓰는데 백그라운드 서비스가 안 돌 수 있음 — 리허설에서 먼저 확인, 시작이 안 되면 이 컷만 실기기로.

**9) 함께 키우기 초대 코드** `09-invite.png` — 슬라이드 6
보여야 할 것: '함께 키우기' 화면 — 8자리 코드, "한 사람만 쓸 수 있고, 7일 뒤 만료됩니다" 안내, 함께 보는 사람 목록.
준비: 마이페이지(홈 상단 아기 이름 탭) → 함께 보는 사람 관리 → '초대 코드 만들기'. 코드는 화면을 벗어나면 다시 못 보므로 만든 직후 촬영.

**10) 공지사항 (서버 주도 콘텐츠)** `10-notice.png` — Q&A 대비(기준 개정·콘텐츠 갱신 질문 카드)
보여야 할 것: 전체 탭 → 공지사항 목록(발행일 포함), 가능하면 글 하나 연 본문(제목·문단·경고 블록) `10b-notice-detail.png`도.
준비: 사전 준비 A-2(시드) 완료.

**11) 다크 모드 홈** `11-home-dark.png` — 슬라이드 10(품질)
보여야 할 것: 1번과 **같은 데이터**의 홈이 다크로 — 라이트/다크 비교 쌍 성립.
준비: 설정 → '다크 모드' 켬 → 홈 탭 → 촬영 → 바로 라이트로 복귀. **반드시 12번(생년월일 수정) 전에** — 수정 후 찍으면 1번과 개월 수가 달라져 비교 컷이 깨짐.

보여야 할 것: 몸무게 차트 — WHO 백분위 곡선들 위에 아이 기록 선·점, **점을 눌러 툴팁('9.6kg')이 뜬 상태**, 0~24개월 축.

| 0개월 | 3.3 | 49.9 |
| 2개월 | 5.6 | 58.4 |
| 4개월 | 7.0 | 63.9 |
| 6개월 | 7.9 | 67.6 |

- 툴팁 촬영 요령: 차트의 점을 마우스로 꾹 누른 채, 미리 쳐 둔 `xcrun simctl io booted screenshot 12-growth-tooltip.png`를 다른 손으로 Enter.

## 찍기 전 점검 5가지
1. **시간대 통일** — 모든 컷의 상태 바 시계를 고정: `xcrun simctl status_bar booted override --time "9:41"`. 앱 안의 기록 시각들(수유 아침·낮, 밤잠 밤)도 하루 흐름처럼 자연스러운지 훑기.
2. **배터리·시계 표시** — 같은 명령에 이어서: `--batteryState charged --batteryLevel 100 --dataNetwork wifi --wifiBars 3 --cellularBars 4`. 촬영이 끝나면 `xcrun simctl status_bar booted clear`.
3. **개인정보 없는 테스트 계정** — 아기 이름은 가명, 계정은 팀 공용(마이페이지에 **이메일 앞부분이 닉네임으로 노출됨**), 피부 사진에 얼굴·신상 없음, 커뮤니티에 실명 글 없음.
4. **언어** — 시뮬레이터 설정 → 일반 → 언어를 **한국어**로. 앱 문구는 한국어 고정이지만 날짜·시간 선택기 같은 시스템 UI가 영어로 나오면 컷을 버리게 됨.
5. **밝기·테마** — 설정의 '시간에 따라 자동'(18시~6시 자동 다크)을 **끄고** 라이트 고정(11번만 다크), 시뮬레이터 Window → Physical Size(100%)에서 촬영, 맥 야간 모드(Night Shift) 꺼짐 확인 — 색 판정 카드(초록/주황/빨강)가 색 그대로 찍혀야 함.
