## 3-5. 기술

프론트엔드는 Flutter/Dart로 iOS와 Android를 함께 지원하며, 인증·데이터베이스·파일
저장은 Supabase가 담당하고 AI 추론은 FastAPI 서버가 처리한다. 외부 AI API 호출을
서버로 한정한 것은 API 키가 앱에 포함될 경우 역컴파일을 통해 탈취될 수 있기 때문이다.

피부 분석은 아토피성 피부염, 흑색종 등 10개 클래스로 구성된 피부 이미지 데이터셋을
학습시킨 자체 분류 모델로 수행하며, 텍스트 기반의 상태 해석과 행동 가이드 생성에는
외부 LLM API 연동 모듈을 활용한다. 푸시 알림은 Firebase Cloud Messaging을 이용한다.

다만 현재 모델은 학습 분할과 평가 분할 사이의 중복 여부를 확인하지 못하였고 정상
피부에 대한 별도의 평가 데이터가 없어, 측정된 성능 수치를 실제 서비스 환경에 대한
일반화 근거로 해석하기 어렵다. 실제 영유아 피부 이미지를 확보한 재검증이 필요하다.

## 3-6. 데이터베이스

데이터베이스는 Supabase가 제공하는 PostgreSQL로 구성한다. 계정 정보는 Supabase
Auth가 별도로 관리하며, 체온·수유·수면·배변·성장·예방접종 등의 기록은 일별 집계를
거치지 않고 아기 정보를 직접 참조한다. 이는 수유와 같이 하루에 여러 번 발생하는
기록을 자연스럽게 수용하고 각 기록이 자체 측정 시각을 보유하도록 하기 위한 설계이다.

규칙 엔진의 판정 결과는 판정 시점의 입력값 스냅샷 및 적용된 규칙 버전과 함께
저장하여, 원본 기록이 이후 수정되더라도 과거 판정과 그 근거가 보존되도록 하였다.
또한 모든 테이블에 행 수준 보안(Row Level Security)을 적용하여, 보호자가 자신의
아기 기록에만 접근할 수 있도록 데이터베이스 차원에서 격리하였다.
