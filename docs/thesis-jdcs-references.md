# 참고문헌 — JDCS 형식 (영문)

JDCS 규정: 참고문헌은 국문 문헌이라도 **모두 영문으로** 작성하고, 논문명·학술지명
구분 없이 **모든 단어의 첫 글자를 대문자**로 처리한다. 본문 인용 순서대로 번호를
매기며, 같은 문헌을 여러 번 인용해도 목록에는 한 번만 올린다.

본문 글꼴: Times New Roman 9pt, 줄간격 150%.
온라인 자료는 하이퍼링크 연결을 해제한다.
