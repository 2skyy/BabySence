## 1. 첫 페이지 (반드시 한 페이지)

템플릿의 고정 항목은 **수정·삭제 금지**입니다.

- 상단 `JDCS / 디지털콘텐츠학회논문지 / Vol. 26, No. 12, pp. 1-4, Dec. 2025`
- 하단 DOI 줄, Open Access 문구, Received/Revised/Accepted 줄

채워야 할 것:

| 항목 | 글꼴 |
|---|---|
| 국문 제목 | 한컴고딕 14pt, 장평 100, 자간 −5, 줄간격 160% |
| 국문 저자 (이 하 늘¹ · 이 유 석¹ · 유 승 환¹ · 오 나 예¹) | 휴먼명조 10.5pt, 자간 −5, 줄간격 120% |
| 국문 소속 | 돋움 8.7pt, 자간 0, 줄간격 130% |
| 영문 제목 | Arial 16.5pt, 자간 0, 줄간격 130% |
| 영문 저자 | Times New Roman 10.5pt, 줄간격 120% |
| 영문 소속 | Arial 8.7pt, 줄간격 130% |
| [요 약] 표제 | 한컴고딕 10pt, 자간 −2, 줄간격 150% |
| 요약 본문 | 바탕 9.1pt, 자간 −5, 들여쓰기 10pt, 줄간격 150% |
| [Abstract] 표제 | Arial 10pt, 자간 −2, 줄간격 150% |
| Abstract 본문 | Times New Roman 9.2pt, 자간 −5, 들여쓰기 10pt, 줄간격 150% |
| 색인어 표제 | 맑은고딕 10pt / 항목 8.7pt |
| Keyword 표제 | Arial 10pt / 항목 8.7pt |

**Abstract는 공백 제외 120~170 words**여야 하고, 국문 요약도 이에 상응하는 길이로
맞춥니다. 현재 원고의 영문 초록은 이보다 깁니다 — **줄여야 합니다.**

색인어와 Keyword는 5개씩, 순서를 서로 맞춥니다. Keyword는 모든 단어의 첫 글자를
대문자로 씁니다.

```
색인어 : 영유아 케어, 의사결정 지원 시스템, 인공지능, 헬스케어 플랫폼, 사용자 경험 평가
Keyword : Infant Care, Decision Support System, Artificial Intelligence, Healthcare Platform,
          User Experience Evaluation
```

교신저자 정보(이름·전화·이메일)를 채우고, **심사용 파일에서는 저자 정보를 모두
삭제**합니다.

## 2. 본문 (서론부터 새 페이지, 2단)

용지 210 × 280 mm, 여백 위·아래 25 mm, 좌·우 20 mm.
본문은 바탕 9.1pt, 들여쓰기 10pt, 줄간격 150%.

### 장·절 번호를 바꿔야 합니다

현재 원고는 `1. 서론` 형식입니다. JDCS는 **로마자 장 번호**를 씁니다.

| 현재 | 고칠 것 |
|---|---|
| `1. 서론` | `Ⅰ. 서  론` (한컴고딕 10pt, 글자 사이 두 칸) |
| `2. 이론적 배경 및 사례 연구` | `Ⅱ. 이론적 배경 및 사례 연구` |
| `3. 플랫폼` | `Ⅲ. 플랫폼` |
| `4. 사용자 경험 평가` | `Ⅳ. 사용자 경험 평가` |
| `5. 결론 및 기대효과, 추후연구` | `Ⅴ. 결  론` |
| `1-1. 연구 배경 및 목적` | `1-1 연구 배경 및 목적` (**마침표 삭제**, 한컴고딕 9.1pt) |

**각 장과 장 사이에는 2줄을 띄웁니다.**

### 지워야 할 것

- 빨간 `※` 검토 메모 전부 (각주·주석은 없어야 한다는 규정)
- 본문의 연도 인용 — `Kim 외(2021)`, `장혜인 외(2025)` 등. JDCS는 번호로만 인용하며,
  부득이 저자명을 쓸 경우에도 연도는 쓰지 않습니다. `[8]`, `[10]`으로 바꿉니다.

### 단위 표기

`%`와 `℃`를 제외한 모든 단위는 수치와 **한 칸 띄웁니다**. 단위 앞뒤에 `[ ]`를 쓰지
않습니다. 본문·표·그림 모두 해당됩니다.

| 고칠 것 | 고친 뒤 |
|---|---|
| `30dB(A)` | `30 dB(A)` |
| `160ml` | `160 mL` |
| `38.0℃` | `38.0℃` (그대로) |

### 약어

처음 나올 때 `의사결정 지원 시스템 (DSS; decision support system)` 형태로 쓰고,
이후에는 약어만 씁니다.

## 3. 그림

### 규정

- **그림 안의 모든 내용은 영문**이어야 합니다.
- 형식은 **jpg 또는 jpeg**.
- 위치는 각 페이지 또는 각 단의 **맨 위나 맨 아래**.
- 캡션은 **그림 아래**, 국문(`그림 N.`) + 영문(`Fig. N.`) **두 줄**.
- 개체 속성에서 **글자처럼 취급**을 켭니다.
- 캡션 글꼴: 국문 돋움 8.5pt(장평 95, 자간 −8) / 영문 Arial 8.5pt(장평 100, 자간 −2),
  줄간격 130%, 내어쓰기 28pt.

### 준비된 파일

`Downloads/jdcs_figures/` 에 있습니다.

| 파일 | 용도 |
|---|---|
| `Fig02_system_architecture.jpg` | 시스템 구성도 (영문판) |
| `Fig_erd_reference.jpg` | 데이터베이스 ERD (영문판) — 본문에서 뺐다면 넣지 않습니다 |

**국문 시스템 구성도는 쓰지 마세요.** 규정 위반입니다. 영문판으로 교체했습니다.

### 한글 UI 캡처 처리

앱 화면 캡처는 UI가 한글이라 그대로는 규정에 어긋납니다. 규정에 예외 절차가 있습니다 —
*"국문이 들어가야만 하는 경우에는 그림과 그림제목 사이에 사유를 별첨표시(\*)하여
영문으로 작성"*. 각 캡처의 그림과 캡션 사이에 아래 한 줄을 넣습니다.

```
* The application interface is provided in Korean because the target users are
  Korean-speaking caregivers.
```

### 캡션 예시

```
그림 1. 예방접종 도우미 화면 구성
Fig. 1. Screen composition of vaccination helper
```

영문 캡션은 **맨 앞 단어의 첫 글자만 대문자**입니다.
